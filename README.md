# Персональный сайт-вишлист

Готовый тёмный premium-вишлист с общей бронью подарков и отдельной админ-панелью.

## Что готово

- публичная адаптивная страница со всеми 57 подарками;
- фильтры, четыре сортировки, раскрываемые описания и кликабельные ссылки;
- бронь и снятие брони с общим состоянием в Firestore;
- `/admin/` со входом только по паролю и CRUD подарков;
- автоматическое первичное заполнение пустой базы;
- серверные правила, ограничивающие гостя изменением только статуса;
- GitHub Actions для бесплатной публикации `dist/` на GitHub Pages;
- документация поддержки в `docs/` и контекст для будущих агентов в `AGENTS.md`.

## Где код сайта

Публикуемая папка — `dist/`. Точки входа:

- `dist/index.html` — публичный список;
- `dist/admin/index.html` — админ-панель.

Перед облачной публикацией нужно один раз подставить Firebase web config и создать единственный аккаунт администратора. Пошагово: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Архитектура, требования, модель данных, безопасность, дизайн и проверки описаны в [docs/README.md](docs/README.md).
