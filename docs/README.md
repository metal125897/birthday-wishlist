# Документация проекта

Актуальная документация для поддержки и развития сайта:

- [PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md) — назначение, роли, функции и границы продукта.
- [ARCHITECTURE.md](ARCHITECTURE.md) — структура файлов, потоки данных и основные решения.
- [DATA_MODEL.md](DATA_MODEL.md) — схема подарка и стартовое наполнение.
- [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — визуальное направление, адаптивность и доступность.
- [SECURITY.md](SECURITY.md) — модель угроз, правила Firestore и ограничения выбранной схемы.
- [DEPLOYMENT.md](DEPLOYMENT.md) — подключение Firebase и бесплатная публикация.
- [HOSTING_OPTIONS.md](HOSTING_OPTIONS.md) — выбранный вариант и запасные платформы.
- [TESTING.md](TESTING.md) — локальные и облачные проверки.
- [DECISIONS.md](DECISIONS.md) — журнал архитектурных решений.

Исторические макеты и исходное большое ТЗ сохранены в корне проекта и папках `screens/`, `wishlist-mockup/`. Они нужны для сверки, но не являются актуальной документацией реализации.
