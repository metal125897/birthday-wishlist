# Значки магазинов

Небольшие значки используются только для узнаваемости ссылок, не как фотографии товаров. Для известных магазинов они находятся в dist/assets/shop-icons/ и не зависят от доступности внешних favicon при просмотре. Проверено 7 ноября 2026.

| Ресурс | Источник |
|---|---|
| goldapple.png | https://goldapple.ru/_static-files/favicons/favicon-32x32.png — официальный HTML магазина указывает этот файл |
| maag.png | https://maag-fashion.com/local/templates/main/favicon-32x32.png — официальный HTML магазина указывает этот файл |
| yandex-market.png | https://avatars.mds.yandex.net/get-marketcms/475644/img-0ec60a9f-2803-4ab0-8408-ed0dd2cbec79.png/favicon_32x32 — официальный HTML market.yandex.ru |
| wildberries.ico | https://www.wildberries.ru/favicon.ico |
| ozon.svg | Авторская золотая монограмма OZ; официальный домен не отдал favicon при проверке |
| henderson.svg | Авторская золотая монограмма H; официальный домен отдавал заглушку, а не пригодный значок |
| rivegauche.svg | Авторская золотая монограмма РГ; официальный домен возвращал 503 |

Три монограммы — обозначения сайта, а не копии официальных логотипов. Оригинальные цвета настоящих favicon сохраняются; серого фильтра нет. Неизвестные домены используют прямой favicon с встроенной иконкой ссылки при отказе; сторонних сервисов иконок нет. Название магазина всегда продублировано текстом.
