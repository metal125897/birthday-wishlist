# Варианты бесплатного размещения

## Выбранный вариант: GitHub Pages + Firebase

Почему выбран:

- нет собственного сервера и ежемесячной оплаты;
- GitHub Pages публикует обычные HTML/CSS/JS из репозитория;
- Firestore даёт бесплатную квоту, значительно превышающую нагрузку личного вишлиста;
- Firebase Auth и Security Rules закрывают админские операции;
- production не зависит от OpenAI.

Ни один зарубежный провайдер не гарантирует доступность из каждой сети РФ. Перед рассылкой ссылки обязательна проверка без VPN с двух операторов.

## Запасной статический хост: GitLab Pages

GitLab Pages также работает с plain HTML, автоматически публикуется через CI/CD, предоставляет HTTPS и доступен на бесплатном тарифе. Переезд не требует менять Firebase или интерфейс — меняется только pipeline публикации. [Документация GitLab Pages](https://docs.gitlab.com/user/project/pages/).

## Запасной backend: Supabase

Supabase подходит как замена Firestore: таблица PostgreSQL, Row Level Security и email/password Auth. Это потребует переписать `firebase-client.js`, запросы в `app.js`/`admin.js` и правила в SQL. Выбирать только после реального теста доступа из целевых сетей РФ.

## Почему не OpenAI Sites

Для локальной разработки Sites удобен, но пользователь явно требует публичный адрес, открывающийся в РФ без VPN. Поэтому итоговый deployment route не должен зависеть от домена или runtime OpenAI Sites.

## Почему не бесплатный VPS

VPS добавляет обслуживание ОС, безопасность, резервные копии и риск окончания промо-тарифа. Для личного вишлиста статический хост + managed database проще и надёжнее.
